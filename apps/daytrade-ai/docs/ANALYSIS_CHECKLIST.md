## C. 리스크 분석 (Risk)

### 단기
- [ ] 포지션·총노출·레버리지 한도 적정성 검토(§8)
- [ ] 당일 손절/익절(±2%) 백테스트 영향 분석
- [ ] 슬리피지 가드 임계값 캘리브레이션

### 중기
- [ ] 실시간 VaR(Monte-Carlo 100 samples) ≤ 0.5% 검증(§12)
- [ ] max-drawdown / 연속손실(streak) 분포 분석
- [ ] 서킷브레이커(>10ms, 손익) 오발동/미발동 케이스 분석
- [ ] 스트레스 테스트(플래시크래시·갭·유동성 소진) 시나리오

### 장기
- [ ] 꼬리위험(tail risk)·블랙스완 헷지 정책
- [ ] 마진콜·강제청산 시뮬레이션
